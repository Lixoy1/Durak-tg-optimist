# OPTIMIST DURAK — аудит игрового движка

## Исправленные дефекты исходного прототипа

1. **Повторный запуск партии:** `startGame()` мог повторно раздать карты уже начатой партии. Теперь старт допустим только из `WAITING_FOR_PLAYERS`.
2. **Очередь атакующих:** исходная логика не описывала переходы достаточно явно. Теперь игрок может подкинуть несколько карт подряд; только действие `PASS` передаёт право следующему доступному атакующему по кругу.
3. **Ранний `PASS`:** исходный код запрещал пасовать, пока остались непобитые карты, что ломало обычный сценарий очередности. Теперь пас завершает право игрока подкидывать в этом раунде, но защитник всё ещё может отбиваться.
4. **Лимит атаки:** лимит теперь зависит от числа карт у защитника в начале раунда, а не от текущего размера его руки. При достижении лимита новые атаки прекращаются, но защитник может закрыть оставшиеся карты.
5. **Первый раунд:** флаг завершения первого раунда выставляется как при успешной защите, так и при взятии карт.
6. **Атомарность действия:** состояние восстанавливается, если действие или проверка инвариантов завершается ошибкой.
7. **Одновременный выход:** игроки, избавившиеся от карт на одной границе раунда после исчерпания колоды, получают одинаковое место, вместо случайного порядка по массиву.
8. **Раздача:** удалена ошибочная пересдача из-за шести карт одной масти; при отсутствии козыря у игроков есть ограниченное число попыток, затем используется детерминированный запасной выбор.
9. **Публичное состояние:** рука каждого игрока включается только в представление для её владельца.

## Правила, которые следует утвердить продуктово

- В этом варианте игрок, нажавший «Пас», больше не подкидывает в текущем раунде.
- При успешном отбое защищавшийся становится основным атакующим следующего раунда; при взятии карт основной атакующий начинает снова, если ещё в игре.
- Одновременное завершение нескольких игроков в конце раунда считается равным местом.
- Первоначальный лимит атаки берётся из `firstBoutMaxCards` и применяется только к первому завершённому раунду. По умолчанию теперь 6 карт, чтобы соответствовать стандартному варианту; значение 5 оставлено только как необязательное домашнее правило.

Эти решения нужно держать едиными в правилах, интерфейсе, ИИ и тестах.
